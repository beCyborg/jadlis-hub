# jadlis-advisor-sales

Мысль: разбор идёт по расшифровке с пронумерованными репликами — каждая находка привязана к номеру, ссылка на несуществующую реплику отбрасывается механической проверкой, а на выходе не больше трёх ходов и признак, по которому сделку пора отпустить.

- Картинка: `docs/img/hero-jadlis-advisor-sales.webp`

- Справа: короткий список ходов на следующий звонок, три строки; подпись «Ходы на следующий звонок»

- Названия сервисов в картинку не идут: только категории
