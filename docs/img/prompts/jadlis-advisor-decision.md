# jadlis-advisor-decision

Мысль: решение проходит гейт, расходится по пяти независимым линзам и двум структурным ролям, отдельный проход метит их утверждения, а арбитр взвешивает линзы по типу среды и сводит всё в один вердикт со ставкой в журнале.
