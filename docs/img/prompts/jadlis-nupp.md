# jadlis-nupp

Мысль: шесть принципов, которые лежат под известными методологиями, проверяются все сразу, каждый получает зелёный, жёлтый или красный сигнал, и красные ранжируются в два-три действия с адресом принципа.

## mindmap

Центральный узел: `nupp`

- **Принципы**: результат и правда, энергия, проактивность, слабое звено, цель действия, повторяемость
- **Диагноз**: сигнал по каждому принципу, красные по влиянию, не больше двух-трёх
- **Антипаттерны**: трайбализм, сбор практик вместо подгонки, «процессы — зло», действие без цели, управление по пожару, всё заново каждый раз
- **Выход**: два-три действия, адрес принципа, названные альтернативы, профиль в память
