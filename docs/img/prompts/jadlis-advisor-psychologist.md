# jadlis-advisor-psychologist

Мысль: разговор идёт в одной названной вслух рамке, а перед ним стоит гейт, который при признаках риска останавливает разбор и отдаёт твои кризисные контакты; полный совет из одиннадцати линз открывается только твоей командой.
