# hub-buy.webp

Мысль: что из набора платное, обязательно и по желанию, с названиями сервисов.
Подписи: «Дополнительные платные подписки», полки «Нужно обязательно» / «По желанию», категории («Компьютер», «Подписка на ИИ», «Синхронизация заметок», «Ключи для голоса и поиска», «Вторая подписка для проверки планов», «Запасной ключ», «Третий ИИ для проверки», «Библиотека») и названия сервисов второй строкой.

Шаг 1 (с нуля; палитра хаба): заголовок «Что платное — без сюрпризов», две полки, восемь плоских предметов с подписями-категориями, без цен.
Шаг 2 (image-to-image): заголовок → «Дополнительные платные подписки».
Шаг 3 — названия сервисов **впечатаны скриптом** `tools/overlay-captions.py` (Pillow, Helvetica Neue Bold 21 px, синий `#1f4bff` / коралл `#ff5a4e`): gpt-image-2 заменяет торговые марки на «APP» (проверено дважды 10.09: «Приложения Mac» → «Приложения APP», список сервисов → «APP, APP API»). Строки: Mac · Claude, тариф Max · Obsidian Sync · ElevenLabs, Anthropic / Brave, Firecrawl · ChatGPT (Codex) · OpenAI · Grok · Anna’s Archive. Координаты — в скрипте.
Выбор владельца 10.09.2026: названия сервисов должны быть в картинке («APP, API — это непонятно»).
