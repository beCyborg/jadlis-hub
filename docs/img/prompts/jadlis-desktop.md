# jadlis-desktop

Мысль: две поверхности за пределами терминала — залогиненный браузер пользователя и нативные приложения Mac, и правило, что пиксели идут последними.

Репозиторий содержит два плагина: `browser` и `computer-use` — по герою на каждый, одна общая схема.
