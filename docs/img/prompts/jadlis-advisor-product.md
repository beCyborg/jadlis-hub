# jadlis-advisor-product

Мысль: продуктовый вопрос читают шестнадцать книжных линз порознь, скептики бьют по совпавшему, а один валидатор пишет файл вердикта в папку памяти.

## hero

- Картинка: `docs/img/hero-jadlis-advisor-product.webp`
- Заголовок: «16 книг отвечают порознь»
- Слева: твой вопрос; подпись «Вопрос»
- В середине: шестнадцать изолированных линз-книг — отдельные карточки, между ними зазор, они не связаны друг с другом; подпись «16 линз-книг порознь»
- Справа: слой скептиков, бьющих по утверждению; подпись «Скептики»
- На выходе: один файл вердикта в папке; подписи «Файл вердикта» и «Папка памяти»
- Названия книг и сервисов в картинку не идут: только категории, обложки пустые
