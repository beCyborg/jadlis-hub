# Тир 0 — рабочее место

Подписка, приложение, четыре команды. На выходе Claude Code знает твой язык, твои
правила ответа и папку, где живут заметки.

## Зачем

Результат на 80% решает контекст о твоей жизни и на 20% — сама задача. Пока контекста
нет, агент угадывает и убедительно ошибается.

Тир 0 строит место, куда этот контекст будет складываться: настроенный Claude Code,
включённая память и папка Obsidian под заметки. Всё остальное на маршруте — тиры 1–6 —
опирается на него.

Плагин `setup` делает это командами, а не инструкцией на двадцать шагов.

## Как поставить

Три шага перед плагином, потом четыре команды.

1. **Подписка Claude.** Claude Code работает на планах Pro, Max, Team и Enterprise.
   Условия и цены — на claude.ai; выбери план там и оплати.
2. **Десктопное приложение Claude Code.** Скачай с
   [страницы установки](https://code.claude.com/docs/en/desktop-quickstart), запусти,
   войди в аккаунт, открой вкладку **Code** и выбери папку.
3. **CLI `claude`.** Приложение его **не ставит** — а команды `claude plugin …` нужны
   для плагинов. Поставит `/setup:deps`; либо руками:
   `curl -fsSL https://claude.ai/install.sh | bash`.

Дальше вставь этот блок в Claude Code целиком:

```text
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-plugins.git
2. Bash: claude plugin install setup@jadlis
3. Скажи мне: «Отправь /reload-plugins, потом напиши /setup:deps»
Ничего не читай, не создавай и не ставь помимо этого.
```

Руками — те же две команды в терминале:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-plugins.git
claude plugin install setup@jadlis
```

Полный HTTPS-URL обязателен: короткая форма `owner/repo` клонируется по SSH, а SSH-ключа
у нового пользователя обычно нет.

## Как пользоваться

Четыре команды по порядку. Каждая спрашивает и показывает дифф до того, как что-то менять.

```text
/setup:deps       # Homebrew, CLI claude, jq, Node.js, git, gh — таблица PASS/FAIL и установка недостающего
/setup:workplace  # ~/.claude: settings.json через jq, CLAUDE.md, память, уведомления, строка состояния
/setup:obsidian   # папка-vault + короткий CLAUDE.md для заметок
/setup:terminal   # опция: iTerm2, tmux, два алиаса — если хочешь терминал вместо приложения
```

Три сценария:

- Чистый Mac: `/setup:deps` → `/setup:workplace` → `/setup:obsidian`.
- Claude Code уже настроен, нужна только папка: сразу `/setup:obsidian`.
- Ответы слишком длинные: `/setup:i-have-adhd` — короткие шаги на текущую сессию.

**Проверка одним действием.** Попроси: «покажи, что лежит в моей папке заметок».
Ответил списком файлов — тир 0 закрыт, дальше `JADLIS-BATCH 1`.

## Границы и стоимость

Чего тир 0 **не** делает:

- Не покупает подписку и не ставит приложение за тебя — это шаги 1–2 выше.
- Не строит структуру папок под методологию и не заводит метрики — это тир 6.
- Не заводит ключи API: они живут в Связке ключей macOS и приезжают на тире 2.
- Не перезаписывает уже существующие `settings.json` и `CLAUDE.md` — сливает и дописывает.

Стоимость: нужна подписка Claude и macOS. Homebrew, jq, Node.js, git, gh и Obsidian —
бесплатны. Ни одного платного запроса тир 0 не делает.

## Десктоп или терминал

Начинай с десктопа: он закрывает весь маршрут 0–6 и не требует возни с шеллом.

Общее у обоих: одни и те же `CLAUDE.md`, `~/.claude/settings.json`, MCP-серверы, хуки,
скиллы, плагины и модели. Настроил в одном — работает в другом.

| Только в терминале | Только в десктопе |
|---|---|
| режим разрешений `dontAsk` | Dispatch-сессии в боковой панели |
| `--print` и Agent SDK — свои запуски по расписанию (`launchd`, `cron`) | задачи по расписанию внутри приложения |
| строка состояния и команды-диалоги (`/permissions`, `/config`, `/keybindings`) | панели чата, диффа, терминала, файлов и браузера |
| команды агентов (agent teams) | отдельный git-worktree на каждую параллельную сессию |
| Remote Control — сессия живёт на машине, продолжается с телефона | вложения: картинки и PDF прямо в промпт |

Отдельно: приложение **не ставит** CLI `claude`. Внутри у него свой встроенный движок,
но команды `claude …` в Bash берутся из отдельной установки — её делает `/setup:deps`.

Терминал добавляют, когда нужны свои запуски по расписанию, `--print` для скриптов или
работа с телефона. Тогда — `/setup:terminal`.
