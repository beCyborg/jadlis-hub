# jadlis-vault — рабочее место: скелет vault, `CLAUDE.md`, первый перезапуск дня

Подшаг 6.1 маршрута передачи. Один скилл `/jadlis-vault:vault-setup` превращает пустую папку в vault, с которым агент умеет работать, и доводит до первой дневной заметки.

## Зачем

Пустая папка и установленный Obsidian — это ещё не система: агент не знает, где что лежит, а человек не знает, куда класть. Самый частый способ похоронить систему — не ошибка в структуре, а тишина: скелет разложили и не начали им пользоваться.

Скилл закрывает оба провала за один проход (тег `jadlis-vault--v1.0.1`):

- Раскладывает скелет папок: `Потребности/`, `Цели/`, `Периоды/День/`, `Знания/`, `AI/verif/`, `Система/`.
- Кладёт `CLAUDE.md` — карту vault и конвенции заметок, которые Claude Code читает в каждой сессии.
- Ставит CSS-сниппет `hide-files` (включать в Obsidian руками).
- Проводит первый вечерний перезапуск дня: три итога, до 5 задач на завтра, готовая завтрашняя заметка.
- Пишет журнал передачи `Система/Передача/состояние.md`.

## Как поставить

Вставь этот блок агенту в Claude Code, открытом в папке vault:

```text
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-plugins.git
2. Bash: claude plugin install jadlis-vault@jadlis
3. Скажи мне одной строкой: «Отправь /reload-plugins, потом напиши: /jadlis-vault:vault-setup»
Ничего не читай, не создавай и не ставь помимо этого.
```

Ручной путь — те же команды:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-plugins.git
claude plugin install jadlis-vault@jadlis
```

Дальше `/reload-plugins` и `/jadlis-vault:vault-setup`. При включении плагин спросит `VAULT_PATH` — путь к папке vault, по умолчанию `~/Jadlis`. Полный HTTPS-URL маркетплейса обязателен: короткая форма `owner/repo` разворачивается в SSH-адрес, а SSH-ключа у нового пользователя обычно нет. Весь подшаг 6.1 можно провести и через драйвер маршрута: `JADLIS-BATCH 6`.

## Как пользоваться

Три типовых сценария:

1. **Первый проход** — `/jadlis-vault:vault-setup`. Скилл сам проверяет, что уже есть, и не перезаписывает существующий `CLAUDE.md`.
2. **Продолжить после Obsidian** — `/jadlis-vault:vault-setup`. Если папку открыли как vault уже после первого прогона, скилл доставит пропущенный сниппет `hide-files` и не тронет остальное.
3. **Проверить, закрыт ли подшаг** — `JADLIS-BATCH статус`. Подшаг 6.1 закрыт, когда есть `CLAUDE.md` **и** хотя бы одна заметка в `Периоды/День/`.

## Границы и стоимость

Что скилл не делает и чего требует:

- **Не создаёт `Смысл жизни.md`, метрики и цели.** Это работа `jadlis-interviewer` (подшаг 6.2); пустая заглушка здесь только помешала бы.
- **Не создаёт папку молча.** Пути `VAULT_PATH` нет — скилл спрашивает, а не угадывает: заметки, ушедшие не туда, — самая дорогая ошибка этого шага.
- **Не трогает `~/.claude/settings.json` и не ставит другие плагины.** Ключей и платных сервисов подшаг не требует вовсе.
- **Obsidian необязателен.** Нет `.obsidian` — скилл пропускает только CSS-сниппет и делает всё остальное; сниппет включается руками в Settings → Appearance → CSS snippets.
- **Ритм держит человек.** Скилл проводит первый вечерний перезапуск; автосбор фактов дня из TickTick, Timing и Health Auto Export сюда не входит и отдельным плагином пока не поставляется.
