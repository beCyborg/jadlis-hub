# jadlis-interviewer — интервью: смысл жизни, метрики, цели квартала

Подшаг 6.2 маршрута передачи. Скилл `/jadlis-interviewer:vault-interviewer` доводит пустой vault до спланированного квартала за четыре этапа — по одному вопросу за реплику, заметки пишет сам.

## Зачем

Цели, взятые из воздуха, невозможно проверить: «хочу миллион» не отвечает на вопрос, какой компонент хорошей жизни это улучшит. А оценка «вроде нормально» не показывает, что именно проседает и куда направлять силы.

Интервьюер переводит слова человека в проверяемую структуру (тег `jadlis-interviewer--v1.0.1`):

- **Этап 1** — заметка «Смысл жизни»: 5–15 предложений его собственными формулировками.
- **Этап 2** — 4–6 групп потребностей, названных его словами, а не чужой таксономией.
- **Этап 3** — 10–15 метрик с направлением, частотой замера и четырьмя диапазонами.
- **Этап 4** — 2–3 цели квартала, каждая привязана к метрике и к kill-критерию с датой.
- Между этапами скилл останавливается и называет, сколько этапов осталось.

## Как поставить

Вставь этот блок агенту в Claude Code, открытом в папке vault:

```text
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
2. Bash: claude plugin install jadlis-interviewer@jadlis
3. Скажи мне одной строкой: «Отправь /reload-plugins, потом напиши: /jadlis-interviewer:vault-interviewer»
Ничего не читай, не создавай и не ставь помимо этого.
```

Ручной путь — те же команды:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install jadlis-interviewer@jadlis
```

Дальше `/reload-plugins` и `/jadlis-interviewer:vault-interviewer`. При включении плагин спросит `VAULT_PATH` — путь к папке vault, по умолчанию `~/Jadlis`. Полный HTTPS-URL маркетплейса обязателен: короткая форма `owner/repo` разворачивается в SSH-адрес, а SSH-ключа у нового пользователя обычно нет. Весь подшаг 6.2 можно провести и через драйвер маршрута: `JADLIS-BATCH 6`.

## Как пользоваться

Три типовых сценария:

1. **Начать интервью** — `/jadlis-interviewer:vault-interviewer`. Скилл сам смотрит, что уже есть в vault, и говорит одной строкой, с какого этапа начинает.
2. **Вернуться через неделю** — та же команда. Это продолжение, а не рестарт: пройденные этапы не переспрашиваются, ориентир — поля `type:` во frontmatter, а не имена папок.
3. **Проверить, закрыт ли подшаг** — `JADLIS-BATCH статус`. Подшаг 6.2 закрыт, когда есть «Смысл жизни», метрик ≥ 10 и целей квартала ≥ 2.

## Границы и стоимость

Что скилл не делает и чего требует:

- **Не проходится за один присест.** Четыре этапа, между ними — остановка и вопрос, продолжать ли; этап 3 честнее делить на два подхода.
- **Потолок метрик жёсткий — 15.** Больше — гарантированно заброшенный список; лишнее уходит в «Кандидаты в метрики». Семь метрик, которые правда меряют, лучше пятнадцати «под число».
- **Не выдумывает за человека.** Чужие числа, чужие показатели и нормы не подставляются; неизвестное поле остаётся пустым, а заимствованный ориентир подписывается источником.
- **Нужен готовый скелет.** Скилл пишет в `Потребности/` и `Цели/` — их раскладывает `jadlis-vault` (подшаг 6.1).
- **Ключей и оплат не требует.** Всё, что нужно, — Claude Code и папка vault; наружу ничего не уходит.
