# Папка-vault для Obsidian

`$ARGUMENTS`

```
VAULT  = ${user_config.VAULT_PATH}
ASSETS = ${CLAUDE_PLUGIN_ROOT}/assets
```

Читателю с СДВГ: **первая строка — действие**, один шаг за реплику.

Этот скилл делает минимум: папку, короткий `CLAUDE.md` и подсказку, что открыть.
Скелет папок под методологию, метрики и перезапуски приезжает на тире 6 плагином
`jadlis-vault` — здесь его не строй.

## Шаг 0 — где мы

```bash
V="${user_config.VAULT_PATH}"; V="${V/#\~/$HOME}"
echo "VAULT=$V"
[ -d "$V" ] && echo "папка есть" || echo "папки НЕТ"
[ -f "$V/CLAUDE.md" ] && echo "CLAUDE.md есть" || echo "CLAUDE.md нет"
[ -d "$V/.obsidian" ] && echo "открыта в Obsidian как vault" || echo ".obsidian нет — папку ещё не открывали как vault"
command -v open >/dev/null 2>&1 && ls -d /Applications/Obsidian.app >/dev/null 2>&1 && echo "Obsidian установлен" || echo "Obsidian не найден в /Applications"
```

## Шаг 1 — папка

**Папки нет — не создавай молча.** Спроси одной строкой: «Папки `<путь>` нет. Создать
её здесь или ты назвал vault иначе?» и жди ответа. Молчаливое создание не туда — самая
дорогая ошибка этого шага: дальше в эту папку лягут все заметки.

Подтвердили — создавай ровно её, без подпапок:

```bash
V="${user_config.VAULT_PATH}"; V="${V/#\~/$HOME}"
mkdir -p "$V"
echo "создано: $V"
```

Название по умолчанию — `Jadlis`: этим именем пользуются пути скиллов и инструкции
плагинов следующих тиров. Назвал иначе — скажи одной строкой, что путь надо будет
указать при установке следующих плагинов (`VAULT_PATH`).

## Шаг 2 — CLAUDE.md в vault

**Файл уже есть — не трогай.** Скажи одной строкой «CLAUDE.md уже на месте» и иди дальше.
Это же правило действует на тире 6: `jadlis-vault` существующий файл не перезаписывает.

Файла нет:

```bash
V="${user_config.VAULT_PATH}"; V="${V/#\~/$HOME}"
cp "${CLAUDE_PLUGIN_ROOT}/assets/vault-CLAUDE.md.template" "$V/CLAUDE.md"
wc -l < "$V/CLAUDE.md" | xargs echo "CLAUDE.md строк:"
```

Что в нём — одной строкой: что это за папка, язык заметок, формат Obsidian-markdown,
куда класть новое и одна ловушка поиска. Методологии в нём нет намеренно: она приедет
на тире 6 и допишет свои разделы.

## Шаг 3 — открыть папку как vault

Одна строка пользователю: «Открой Obsidian → **Open folder as vault** → выбери `<путь>`».
Obsidian не установлен — вторая строка: скачать бесплатно на obsidian.md.

После этого в папке появится `.obsidian` — по нему видно, что связка работает.

## Шаг 4 — плагины Obsidian

Покажи таблицу и остановись: ставит их человек руками через
Settings → Community plugins → Browse. Автоматизировать это не надо.

| Плагин | Зачем |
|---|---|
| `folder-notes` | у папки появляется своя заметка-обложка |
| `obsidian-linter` | автоформат заметок при сохранении |
| `manual-sorting` + `dragger` | ручной порядок файлов и перетаскивание |
| `iconic` + `my-svgs` | иконки папок и заметок |
| `advanced-canvas` + `editing-toolbar` | схемы на canvas и панель форматирования |

Плюс две строки:

- Тема **Border**: Settings → Appearance → Themes → Browse.
- `obsidian-style-settings` и `sidebar-highlights` — по вкусу: настройки темы без правки
  CSS и выделения в боковой панели.

Плагины дневных и недельных заметок (`periodic-notes`, `daily-note-calendar`) здесь
не ставим — они идут в комплекте с методологией на тире 6.

## Шаг 5 — проверка одним действием

```bash
V="${user_config.VAULT_PATH}"; V="${V/#\~/$HOME}"
ls -a "$V" | sed 's/^/  /'
```

Затем ровно две строки:

1. Что теперь работает: папка `<путь>` открыта как vault, `CLAUDE.md` на месте.
2. Дальше: тир 0 закрыт → `JADLIS-BATCH 1`. Хочется терминал вместо приложения —
   сначала `/setup:terminal`.

## Чего не делать

- Не создавать папку без подтверждения пути.
- Не строить скелет папок методологии (`Потребности/`, `Цели/`, `Периоды/`) — это тир 6.
- Не перезаписывать существующий `CLAUDE.md` в vault.
- Не ставить плагины Obsidian за человека и не лезть в `.obsidian/` руками при
  открытом Obsidian — правки затираются.
- Не пересказывать шаблон целиком: одна строка о том, что в нём.
