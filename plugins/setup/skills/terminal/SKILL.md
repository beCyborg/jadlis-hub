# Терминальный путь — опция, не требование

`$ARGUMENTS`

Читателю с СДВГ: **первая строка — действие**, один шаг за реплику. Этот скилл
ничего не обязателен: десктопного приложения хватает для всего маршрута 0–6.

## Шаг 1 — сравнение одной таблицей

Напечатай таблицу и остановись. Не начинай ставить пакеты, пока не спросил.

| | Десктоп | Терминал |
|---|---|---|
| Настройки, `CLAUDE.md`, скиллы, MCP, плагины | одни и те же файлы | одни и те же файлы |
| Панели, диффы, worktrees, вложения, Dispatch | есть | нет |
| Управление с телефона (Remote Control) | запускается из CLI или VS Code | есть |
| Автоматика по расписанию | Scheduled tasks в приложении | `--print` + `launchd`/`cron` |
| Строка состояния, режим `dontAsk`, команды-диалоги | нет | есть |

Одна строка вывода: **начинать стоит с десктопа**. Терминал добавляют, когда нужны
свои запуски по расписанию, `--print` для скриптов или работа с телефона.

Полное сравнение — в `docs/0-workplace` репозитория, раздел «Десктоп или терминал».
Пересказывать его целиком не надо.

## Шаг 2 — спросить, идём ли дальше

`AskUserQuestion`, три вопроса, каждый с одной строкой «зачем»:

1. Ставим iTerm2? — терминал с вкладками и нормальной работой с цветом.
2. Ставим tmux? — сессии переживают закрытие окна; нужен для работы с телефона.
3. Добавляем два алиаса в `.zshrc`? — короткий запуск и продолжение прошлой сессии.

Ответ «нет» на всё — скажи одной строкой «остаёмся на десктопе, дальше `/setup:obsidian`»
и остановись.

## Шаг 3 — пакеты

```bash
command -v brew >/dev/null 2>&1 || echo "нет brew — сначала /setup:deps"
brew install --cask iterm2
brew install tmux
```

Одна строка результата на пакет, без вывода `brew` целиком. iTerm2 после установки
надо открыть руками из папки «Программы» — скажи это одной строкой.

## Шаг 4 — алиасы

Сначала проверь, не заняты ли имена — молча перетирать чужой алиас нельзя:

```bash
grep -nE "^alias (cc|cld)=" "$HOME/.zshrc" 2>/dev/null || echo "имена свободны"
```

Заняты — предложи другие имена и спроси. Свободны — покажи ровно эти две строки
и спроси «дописываем?»:

```bash
cat >> "$HOME/.zshrc" <<'ALIASES'

# Claude Code
alias cc='claude'
alias cld='claude --continue'
ALIASES
```

- `cc` — запустить Claude Code в текущей папке.
- `cld` — продолжить последнюю сессию в этой папке.

Применяются в новом окне терминала или после `source ~/.zshrc`. Скажи это одной строкой.

## Шаг 5 — проверка одним действием

```bash
zsh -ic 'alias cc cld' 2>/dev/null | sed 's/^/alias: /'
command -v tmux >/dev/null 2>&1 && echo "tmux PASS" || echo "tmux нет"
```

Затем две строки: что теперь работает и «дальше: `/setup:obsidian`».

## Чего не делать

- Не навязывать терминал: десктоп закрывает весь маршрут, это разветвление вкуса.
- Не переписывать `.zshrc` целиком и не трогать чужие строки — только дописать блок в конец.
- Не ставить оболочки, темы, prompt-фреймворки и плагины сверх названных трёх пунктов.
- Не показывать вывод `brew install` целиком.
