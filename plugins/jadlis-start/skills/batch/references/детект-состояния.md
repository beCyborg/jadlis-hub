# Детект состояния — пробы машины по тирам 0–6

Состояние определяется **пробами машины, а не словами пользователя**. Человек искренне
считает, что «тир 0 сделан», когда открыл Claude Code. Проба этого не подтвердит, пока
нет `jq`, Node.js и папки vault — и правильно.

## Один блок

Подставь вместо `{VAULT_PATH}` реальный путь (он дан в SKILL.md) и выполни **одним**
Bash-вызовом. Блок ничего не меняет — только читает. Значения ключей не печатает:
только «есть/нет».

```bash
V="{VAULT_PATH}"; case "$V" in "~"*) V="$HOME${V#\~}";; esac
S="$HOME/.claude/settings.json"
have(){ command -v "$1" >/dev/null 2>&1 && echo да || echo нет; }
PL=$(claude plugin list 2>/dev/null)
inst(){ printf '%s\n' "$PL" | command grep -q "❯ $1@" && echo да || echo нет; }
enabled(){ printf '%s\n' "$PL" | awk -v p="❯ $1@" 'index($0,p){f=1} f&&/Status:/{print; exit}' | command grep -q enabled && echo да || echo нет; }
cnt(){ printf '%s' "$1" | tr -d ' '; }

# ── Тир 0: рабочее место ───────────────────────────────────────────────────
c0=$(have claude); j0=$(have jq); n0=$(have node); x0=$(have npx)
cm=нет; [ -f "$HOME/.claude/CLAUDE.md" ] && cm=да
vd=нет; [ -d "$V" ] && vd=да
mem=$(jq -r 'if .autoMemoryEnabled == null then "не задано" else (.autoMemoryEnabled|tostring) end' "$S" 2>/dev/null || echo "нет settings")
t0=нет; [ "$c0$j0$n0$x0$cm$vd" = "дададададада" ] && t0=да
echo "ТИР0 закрыт=$t0 claude=$c0 jq=$j0 node=$n0 npx=$x0 CLAUDE.md=$cm папка_vault=$vd память=$mem"

# ── Тир 1: Spokenly настроен ───────────────────────────────────────────────
P="$HOME/Library/Containers/app.spokenly/Data/Library/Preferences/app.spokenly.plist"
t1=нет; mp=""; ap=0; wr=0
if [ -f "$P" ]; then
  mp=$(plutil -extract mainPrompt      raw -o - "$P" 2>/dev/null)
  ap=$(plutil -extract aiProviders     raw -o - "$P" 2>/dev/null | base64 -d 2>/dev/null \
        | python3 -c 'import json,sys;print(len(json.load(sys.stdin)))' 2>/dev/null)
  wr=$(plutil -extract wordReplacements raw -o - "$P" 2>/dev/null | base64 -d 2>/dev/null \
        | python3 -c 'import json,sys;print(len(json.load(sys.stdin)))' 2>/dev/null)
  [ -n "$mp" ] && [ "${ap:-0}" -ge 2 ] 2>/dev/null && [ "${wr:-0}" -ge 1 ] 2>/dev/null && t1=да
fi
echo "ТИР1 закрыт=$t1 spokenly=$([ -f "$P" ] && echo да || echo нет) промпт_символов=${#mp} провайдеров=${ap:-0} замен=${wr:-0}"

# ── Тир 2: ключи + verif ───────────────────────────────────────────────────
pr=$(inst jadlis-research); en=$(enabled jadlis-research)
kb=нет; kf=нет
SEC=$(security find-generic-password -s "Claude Code-credentials" -w 2>/dev/null)
if [ -n "$SEC" ]; then
  printf '%s' "$SEC" | jq -e '.pluginSecrets["jadlis-research@jadlis"].BRAVE_API_KEY // empty'     >/dev/null 2>&1 && kb=да
  printf '%s' "$SEC" | jq -e '.pluginSecrets["jadlis-research@jadlis"].FIRECRAWL_API_KEY // empty' >/dev/null 2>&1 && kf=да
fi
unset SEC
[ "$kb" = нет ] && [ -n "$BRAVE_API_KEY" ] && kb=да
[ "$kf" = нет ] && [ -n "$FIRECRAWL_API_KEY" ] && kf=да
vf=$(cnt "$(ls "$V/AI/verif/"*.md 2>/dev/null | wc -l)")
t2=нет; [ "$pr$en$kb$kf" = "дададада" ] && [ "${vf:-0}" -ge 1 ] && t2=да
echo "ТИР2 закрыт=$t2 плагин=$pr включён=$en Brave=$kb Firecrawl=$kf вердиктов=${vf:-0}"

# ── Тир 3: ресерч ──────────────────────────────────────────────────────────
rp=$(cnt "$(ls "$V/Знания/Ресерчи/"*.md 2>/dev/null | wc -l)")
sk=нет; security find-generic-password -s jadlis-research -a PUBMED_API_KEY >/dev/null 2>&1 && sk=да
[ "$sk" = нет ] && jq -e '.env.PUBMED_API_KEY // empty' "$S" >/dev/null 2>&1 && sk=да
t3=нет; [ "$t2" = да ] && [ "${rp:-0}" -ge 2 ] && t3=да
echo "ТИР3 закрыт=$t3 отчётов=${rp:-0} научные_ключи=$sk"

# ── Тир 4: свои сотрудники ─────────────────────────────────────────────────
sc=$(inst skill-creator); pc=$(inst plugin-creator)
os=$(cnt "$(ls -d "$HOME/.claude/skills/"*/ 2>/dev/null | wc -l)")
t4=нет; [ "$sc$pc" = "дада" ] && [ "${os:-0}" -ge 1 ] && t4=да
echo "ТИР4 закрыт=$t4 skill-creator=$sc plugin-creator=$pc своих_скиллов=${os:-0}"

# ── Тир 5: советы директоров ───────────────────────────────────────────────
ad=$(inst advisors)
AM=$(jq -r '.pluginConfigs["advisors@jadlis"].options.ADVISORS_MEMORY_DIR // "~/advisors-memory"' "$S" 2>/dev/null); AM=${AM:-~/advisors-memory}
case "$AM" in "~"*) AM="$HOME${AM#\~}";; esac
av=$(cnt "$(find "$AM/Вердикты" -name '*.md' ! -name README.md 2>/dev/null | wc -l)")
t5=нет; [ "$ad" = да ] && [ "${av:-0}" -ge 1 ] && t5=да
echo "ТИР5 закрыт=$t5 плагин=$ad вердиктов=${av:-0}"

# ── Тир 6: методология — три подшага ───────────────────────────────────────
jv=$(inst jadlis-vault); cl=нет; [ -f "$V/CLAUDE.md" ] && cl=да
dn=$(cnt "$(ls "$V/Периоды/День/"*.md 2>/dev/null | wc -l)")
t61=нет; [ "$cl" = да ] && [ "${dn:-0}" -ge 1 ] && t61=да
ji=$(inst jadlis-interviewer); sm=нет; [ -f "$V/Смысл жизни.md" ] && sm=да
mt=$(cnt "$(command grep -rl '^type: metric$' "$V/Потребности" 2>/dev/null | wc -l)")
gl=$(cnt "$(ls -d "$V/Цели/"*Q*/ 2>/dev/null | while read -r d; do ls "$d"*.md 2>/dev/null; done | wc -l)")
t62=нет; [ "$sm" = да ] && [ "${mt:-0}" -ge 10 ] && [ "${gl:-0}" -ge 2 ] && t62=да
sw=$(inst swot-news)
sn=$(cnt "$(find "$V" -type d -name 'SWOT' -exec find {} -name '*.md' \; 2>/dev/null | wc -l)")
t63=нет; [ "$sw" = да ] && [ "${sn:-0}" -ge 1 ] && t63=да
t6=нет; [ "$t61$t62$t63" = "дадада" ] && t6=да
echo "ТИР6 закрыт=$t6 | 6.1 vault=$t61 (плагин=$jv CLAUDE.md=$cl дневных=${dn:-0}) | 6.2 интервью=$t62 (плагин=$ji смысл=$sm метрик=${mt:-0} целей=${gl:-0}) | 6.3 swot=$t63 (плагин=$sw заметок=${sn:-0})"

# ── Журнал (только «где я внутри тира», не «закрыт ли он») ─────────────────
J="$V/Система/Передача/состояние.md"
[ -f "$J" ] && echo "ЖУРНАЛ есть: $(command grep -m1 '^тир:' "$J" 2>/dev/null)" || echo "ЖУРНАЛ отсутствует"
```

## Таблица критериев

| Тир | Проба | «Закрыт», если |
|---|---|---|
| 0 | `command -v` + файлы | есть `claude`, `jq`, `node`, `npx`; есть `~/.claude/CLAUDE.md`; папка vault существует |
| 1 | `plutil` по плисту Spokenly | `mainPrompt` непуст, `aiProviders` ≥ 2, `wordReplacements` ≥ 1 |
| 2 | `claude plugin list` + Keychain + артефакты | `jadlis-research` стоит **и** включён, Brave и Firecrawl заданы, ≥ 1 файл в `AI/verif/` |
| 3 | артефакты | тир 2 закрыт **и** отчётов в `Знания/Ресерчи/` ≥ 2 |
| 4 | `claude plugin list` + `~/.claude/skills` | стоят `skill-creator` и `plugin-creator` **и** ≥ 1 свой скилл |
| 5 | `claude plugin list` + папка памяти | стоит `advisors` **и** ≥ 1 вердикт в `Вердикты/` |
| 6.1 | `CLAUDE.md` + `Периоды/День/*.md` | файл есть **и** ≥ 1 дневная заметка |
| 6.2 | `Смысл жизни.md` + метрики + цели | все три: файл есть, метрик ≥ 10, целей квартала ≥ 2 |
| 6.3 | `claude plugin list` + заметки SWOT | стоит `swot-news` **и** ≥ 1 заметка в папке `SWOT` |

Тир 6 закрыт, когда закрыты все три подшага. Внутри тира порядок 6.1 → 6.2 → 6.3.

## Как читать результат

- Тир 0: `claude=да`, а `jq=нет` → десктоп поставлен, CLI-зависимости нет. Это самый частый провал тира 0: десктопное приложение **не ставит** CLI и его окружение.
- Тир 1: `mainPrompt` пуст → Spokenly стоит, промпт-корректор не перенесён.
- Тир 2: `плагин=да включён=нет` → поставлен, но не включён (`jadlis-research` ставится выключенным — это норма). `Brave=нет` → ключ не введён. `вердиктов=0` → verif не запускали.
- Тир 3: `отчётов=1` → один прогон был, второго (другого инструмента) нет.
- Тир 4: плагины стоят, `своих_скиллов=0` → сотрудника ещё не написали.
- Тир 5: `вердиктов=0` → совет ни разу не собирали.
- Тир 6.1 не закрыт при существующем `CLAUDE.md` → скелет разложен, вечерний ритм не начался. Метрик 4 из 10 → интервью идёт, «внутри 6.2».

## Расхождение с журналом

Журнал `Система/Передача/состояние.md` отвечает **только** на «где я внутри тира».
На вопрос «закрыт ли тир» отвечают пробы.

Журнал говорит «тир 2 закрыт», пробы — нет: перепиши журнал по пробам и скажи об этом
**одной строкой**, без разбирательства: «Журнал говорил, что тир 2 закрыт, но вердиктов 0 —
поправил журнал по факту».

## Послабления

- verif штатно работает и на **одном Claude**, если Codex/Grok не поставлены: вердикт есть — тир 2 закрыт. Не отправляй чинить провайдеров как условие закрытия.
- Пробу тира 5 не видно, если папка памяти задана не по умолчанию и её нет в `pluginConfigs` — спроси путь одной строкой и проверь `find` руками.
