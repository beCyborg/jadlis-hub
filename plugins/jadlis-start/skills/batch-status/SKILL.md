# Статус передачи Jadlis

```
VAULT = ${user_config.VAULT_PATH}
```

Только чтение. Ничего не ставить, не создавать, не править — даже если по пробам видно,
что чего-то не хватает.

1. Прочитай `${CLAUDE_PLUGIN_ROOT}/skills/batch/references/детект-состояния.md` и выполни
   описанный там блок, подставив `VAULT` вместо `{VAULT_PATH}`.

2. Напечатай ровно восемь строк — семь тиров и текущий:

```
0 Рабочее место        ✅ закрыт
1 Голос (Spokenly)     ✅ закрыт
2 Ключи и verif        ⏳ плагин стоит, Brave есть, Firecrawl нет, вердиктов 0
3 Ресерч               ⬜ не начат
4 Свои сотрудники      ⬜ не начат
5 Советы директоров    ⬜ не начат
6 Методология          ⬜ 6.1 vault ⬜ · 6.2 интервью ⬜ · 6.3 SWOT ⬜

Твой тир сейчас: 2 → напиши `JADLIS-BATCH 2`
```

Незакрытый тир показывай **цифрами из проб**, а не словами «не завершён». Прозой пробы
не пересказывай, Bash-вывод целиком не показывай, значения ключей не печатай.

3. Журнал расходится с пробами — скажи об этом одной строкой и не трогай журнал:
   переписывает его драйвер, не этот скилл.
