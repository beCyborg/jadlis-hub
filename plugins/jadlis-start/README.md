# jadlis-start — драйвер маршрута 0–6

Один плагин, который знает, на каком ты шаге, и выдаёт ровно следующий. Ничего авансом.

## Зачем

Стек из десятка плагинов нельзя поставить за вечер — утонешь. Драйвер ведёт по семи тирам: инструменты сначала (рабочее место, голос, ключи и verif, ресерч, свои сотрудники, советы), методология в конце. Следующий тир не выдаётся, пока пробы машины не подтвердят предыдущий.

## Как поставить

Вставь в чат Claude Code:

```
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
2. Bash: claude plugin install jadlis-start@jadlis
3. Скажи мне: «Отправь /reload-plugins, потом напиши: JADLIS-BATCH»
```

Те же две команды руками в терминале:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install jadlis-start@jadlis
```

## Как пользоваться

- `JADLIS-BATCH` — статус семи тиров и следующий шаг.
- `JADLIS-BATCH 2` — выдать тир 2: поставить плагин, объяснить первый запуск.
- `JADLIS-BATCH 6.2 продолжить` — вернуться внутрь подшага после перерыва (продолжение, не рестарт).

Только статус без установки: `/jadlis-start:batch-status`.

## Границы и стоимость

- Не выдаёт тир N, пока не закрыт N−1: критерии — в `skills/batch/references/детект-состояния.md`.
- Не читает и не печатает значения ключей — только «есть/нет» по Связке ключей.
- Тир 1 (голос) ставится руками вне Claude Code; драйвер только проверяет результат.
- Бесплатен. Платные сервисы появляются на тире 2 (Brave, Firecrawl) и дальше — об этом говорят доки каждого тира.

## Обновление

У сторонних маркетплейсов auto-update у получателя выключен:

```bash
claude plugin update jadlis-start@jadlis
```
