# jadlis-hub — помощник маршрута

Один плагин, который знает, на каком ты шаге, и выдаёт ровно следующий. Ничего авансом.

## Зачем

Стек из десятка плагинов нельзя поставить за вечер — утонешь. Помощник ведёт по шести обязательным шагам (рабочее место, Obsidian, голос, поиск, ресерч, проверка планов), а после них открывает необязательные инструменты в рекомендованном порядке. Следующий шаг не выдаётся, пока пробы машины не подтвердят предыдущий.

## Как поставить

Вставь в чат Claude Code:

```
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
2. Bash: claude plugin install jadlis-hub@jadlis
3. Скажи мне: «Отправь /reload-plugins, потом напиши: /jadlis-hub»
```

Те же две команды руками в терминале:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-hub@jadlis
```

## Как пользоваться

- `/jadlis-hub` — маршрут со статусами и следующий шаг.
- `/jadlis-hub status` — только отчёт, ничего не ставится.
- `/jadlis-hub search` — выдать шаг: объяснить простым языком, поставить плагин, передать его команде.
- `/jadlis-hub later` — что будет дальше: советы директоров и `jadlis-os`.

## Границы и стоимость

- Не выдаёт шаг, пока не закрыт предыдущий обязательный: критерии — в `references/probes.md`, данные маршрута — в `references/route.json`.
- Не читает и не печатает значения ключей — только «есть/нет» по Связке ключей.
- Перед каждым шагом называет, что придётся купить, до установки, а не на середине.
- Сам бесплатен; платные сервисы начинаются с подписки Claude на шаге 1 и ключей поиска на шаге 4.

## Обновление

У сторонних маркетплейсов auto-update у получателя выключен:

```bash
claude plugin update jadlis-hub@jadlis
```
